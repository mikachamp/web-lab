Key Architectural Strengths
  • True 3D Spatial Freedom: 6-DOF camera orbits, depth-tested occlusions, and real lighting.
  • Headless Screenshot Testing: Deterministic timeline enables headless CI/CD pixel diffs.
  • Video Export Pipeline: Headless frame capture via `ffmpeg` into 4K 60fps MP4 master reels.
Critical Limitations to Manage
  • No Native DOM Reflow: Cannot use standard HTML text wrapping or responsive flexbox.
  • Accessibility Gap: Screen readers cannot parse canvas pixels without parallel ARIA trees.
  • Mobile Battery/Thermals: Continuous render loops consume GPU power unless paused when idle.
